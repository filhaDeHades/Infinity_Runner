# Workshop Criando um Infinity Runner na Godot

Esse repositório tem como objetivo ilustrar o conteúdo passado no Workshop ... , organizado em parceria entre o [Include Meninas](https://www.instagram.com/includemeninas/) e o [DJUFF](https://www.instagram.com/djuff.oficial/), ambos projetos de extensão do Instituto de Computação da UFF - Niterói.

Durante o workshop as participantes aprenderam a:

- Importar e configurar sprites
- Configurar animações
- Programar a movimentação de um personagem
- Utilizar o efeito Paralax
- Adicionar música de fundo (Ambient Music)
- Criação de um menu básico (Limitado ao tempo)

Software e Assets utilizados:

- [Godot 3.5](https://godotengine.org/download/archive/3.5-stable/)
- [Tileset por mem-px](https://mem-px.itch.io/2d-platformer-16x16)
- [Personagem por mem-px](https://mem-px.itch.io/2d-pixel-art-character)
- [Música de Fundo - Sketchbook 2024-06-09](https://tallbeard.itch.io/music-loop-bundle)
- [UI Sprites por ToffeeCraft](https://toffeecraft.itch.io/ui)
